# คะแนนรายเซตและการ์ดผลการแข่งขัน

## ใช้งาน

- เมนู **ผลการแข่งขัน** แสดงคะแนนจบคู่และแต้มรายเซตของคู่ที่ยืนยันแล้วตามรายการที่เลือก
- คลิกการ์ดเพื่อเปิดรายละเอียด: โรงเรียนเต็ม ผู้ชนะ คะแนนรวม แต่ละเซต รอบ เลขคู่ วัน/ช่วงเวลาจากสูจิบัตร สนาม และคะแนนลีกเมื่อเป็นรอบแบ่งสาย/พบกันหมด
- หน้าแรกแสดงการ์ดผลล่าสุดที่คลิกได้ หน้าตารางมีปุ่มดูผล และกรรมการเปิดรายละเอียดจากคู่ที่บันทึกแล้วได้
- ผู้ชมเห็นผลสาธารณะ โรงเรียนเห็นคู่ของตน กรรมการเห็นเฉพาะคู่ที่มอบหมาย การดูการ์ดไม่เพิ่มสิทธิ์แก้ไข

## การกรอก

วอลเลย์บอล/ตะกร้อรองรับชนะ 2 ใน 3 เซต กรอกแต้มสองทีมของสองเซตแรก เพิ่มเซตสามเมื่อเล่นจริง ระบบนับเซตชนะเป็นคะแนนจบคู่ ตรวจเลขจำนวนเต็ม 0–999 ห้ามเซตเสมอ ห้ามเพิ่มเซตหลังมีทีมชนะสองเซต และตรวจผลรวมก่อนยืนยัน

ไม่กำหนดแต้มขั้นต่ำ ดิวซ์ หรือเพดานเซตสามแทนระเบียบผู้จัด กรรมการยังต้องกรอกตามกติกาการแข่งขันจริง กีฬาอื่นบันทึกคะแนนจบคู่ตามเดิม ผลเก่าที่ไม่มีแต้มรายเซตจะระบุว่าไม่มีข้อมูล ไม่สร้างแต้มย้อนหลังเอง

## ความคงทนและสิทธิ์

ใช้ JSON `registration_policy.matchReports` ใน competitions เดิม ไม่มี migration/คอลัมน์/constraint/RLS ใหม่ รายเซตเก็บเป็นประวัติแต่ละความพยายาม โดยอ่านเฉพาะรายการที่ตรงกับ revision, updated_at และคะแนนรวมของ match ที่บันทึกสำเร็จ มี CAS และการจัดสรร timestamp ระดับไมโครวินาทีจากค่าใน policy ที่บันทึกจริง ไม่ใช้ตัวนับเฉพาะ process จึงไม่ทับแต้มของอีกอุปกรณ์

การแก้โควตา/ผังใช้ guard ของ matchReportsVersion ร่วมกับ management revision เพื่อไม่เขียนทับผลเซต การแก้เฉพาะคะแนนรวมทำให้รายเซตเวอร์ชันเก่าไม่ถูกนำมาแสดง ผู้เขียนที่ไม่มีสิทธิ์หรือไม่ได้รับมอบหมายถูกปฏิเสธก่อนเขียนข้อมูล

ประวัติรายเซตจะสะสมใน JSON ยังไม่มีการล้างประวัติอัตโนมัติ เพื่อไม่ลบความพยายามที่อยู่ระหว่างบันทึก
