## สิ่งที่เก็บและสิ่งที่รอผู้จัด

- เก็บสายการแข่งขัน เลขคู่ต้นฉบับ และป้ายผู้ชนะ/ผู้แพ้/อันดับสายไว้ใน `registration_policy.management` เลขคู่ฟุตบอลมัธยมไม่เรียงต่อกันตามต้นฉบับ
- รอบแบ่งสายเสมอได้ รอบแพ้คัดออกต้องมีผู้ชนะ ผู้แพ้รอบรองไปชิงอันดับ 3
- ผู้ดูแลเลือกทีมเข้ารอบจากสายที่ระบุ รวมถึงอันดับสองที่ดีที่สุดตามระเบียบผู้จัด ระบบไม่สมมติกติกาตัดสินอันดับ
- วันเวลา สนาม และกรรมการรอแก้ภายหลัง ช่องคู่แข่งขันยังไม่เป็นแถว `matches` จนมีผู้แข่งขันจริง วันเวลาและสนามครบ ผังสาธารณะแสดงช่องคู่ทั้งหมดพร้อมข้อความรอกำหนดเวลา/สนาม โดยแยกข้อมูลแสดงผลออกจากนัดจริงและผลการแข่งขัน
- แชร์บอลและโยนบอลยังไม่กำหนดจำนวนสำรอง จนผู้จัดระบุ
- กรีฑารอตารางเพศ/อายุ ใช้โควตาประเภทเดี่ยวหนึ่งตัวแทนโรงเรียนต่อรายการ ไม่กำหนดหนึ่งรายการต่อนักกีฬา วิ่งผลัดเป็นทีม 4 ตัวจริงและสำรองไม่เกิน 4 คน
- ไม่สร้างเปตองหรือรุ่นอื่นที่ไม่มีในภาพ

## การแทนข้อมูลจำลอง

นำเข้าและตรวจอ่านกลับแล้ว: 8 รายการ / 80 ช่องคู่ / 0 นัดที่มีเวลา ย้ายชื่อโรงเรียน `banrailampang` เป็น `โรงเรียนบ้านไร่ลำปาง` โดยใช้ UUID เดิม เก็บทั้ง 12 แถวโรงเรียน (11 โรงเรียนจากภาพและโรงเรียนตัวอย่างเดิม) และ 14 profiles ไว้ครบ

สำรองข้อมูลเดิมไว้ภายในเครื่องนอก Git ที่ `.local-backups/image-program-2569-20261109.json` (สิทธิ์ 600) ก่อนลบเฉพาะรายการเปตองจำลอง U12 ผสมและทะเบียนจำลองหนึ่งคน ไม่มีการลบบัญชีหรือเปลี่ยนรหัสผ่าน

## การตรวจสอบ

ชุด Node tests ครอบคลุมจำนวนรายการ/คู่ สาย เลขคู่อ้างอิง การจับคู่ UUID การเสมอรอบแบ่งสาย การเลือกทีมเข้ารอบ ผู้แพ้ไปชิงอันดับ 3 และการรอครบทุกคู่ก่อนแจกเหรียญลีก ผ่าน typecheck และ production build โดยไม่รัน E2E ตามคำสั่งผู้จัด
