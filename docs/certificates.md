# เกียรติบัตรนครโกสัมพีเกมส์ 2569

เมนู **เกียรติบัตร** แสดงสำหรับผู้ดูแลและบัญชี school/school_admin ผู้ดูแลตรวจรายชื่อจากผลที่ครบและยืนยันแล้วก่อนเผยแพร่ โรงเรียนดาวน์โหลดได้เฉพาะเกียรติบัตรที่เผยแพร่ของโรงเรียนตนเอง

## วิธีใช้

1. ผู้ดูแลเลือกการแข่งขันแล้วกด **ตรวจสอบรายชื่อก่อนออก** หากมีผลหรือรายชื่อไม่ครบ ระบบจะแสดงเหตุผลและไม่ให้เผยแพร่
2. ใน **ตั้งค่าแม่แบบเกียรติบัตร** ดาวน์โหลดตัวอย่าง PDF ตรวจฟอนต์ พื้นหลัง และตำแหน่งข้อความได้ก่อนออกจริง
3. กด **ยืนยันออกเกียรติบัตร** เพื่อบันทึกสำเนารายชื่อ รางวัล และเวอร์ชันพื้นหลังที่ใช้ โรงเรียนจึงดาวน์โหลดได้
4. เลือกโรงเรียน/รายชื่อเพื่อดาวน์โหลดรายคนหรือ PDF รวม (ไม่เกิน 50 ฉบับ) หรือ ZIP แยกไฟล์ (ไม่เกิน 10 ฉบับ และขนาดผลลัพธ์ไม่เกิน 4 MB; ชุดพื้นหลังใหญ่ให้ใช้ PDF รวมซึ่งฝังภาพร่วมกันครั้งเดียว)
5. หากชื่อ ผล หรือแม่แบบผิด ให้ยกเลิกการเผยแพร่ ตรวจข้อมูลใหม่แล้วออกอีกครั้ง QR ฉบับเดิมจะใช้ยืนยันไม่ได้ ไม่มีการแก้ไขฉบับที่ออกไปแล้วแบบเงียบ ๆ

## เปลี่ยนพื้นหลังด้วย Base64

ผู้ดูแลเลือก PNG/JPEG หรือวาง Base64 แบบดิบ/แบบ `data:image/png;base64,...` แล้วกดใช้ในตัวอย่าง ปรับตำแหน่งชื่อ โรงเรียน ประเภทผู้รับ รายการ รางวัล และ QR ก่อนบันทึกแม่แบบ ภาพใหม่มีผลกับการออกครั้งถัดไปเท่านั้น

จำกัดภาพใหม่หลังถอดรหัสไม่เกิน 1,300,000 ไบต์ และเอกสาร JSON ไม่เกิน 1.9 MB เพื่อใช้ bucket เดิมที่จำกัด 2 MB ไม่ลดความละเอียดหรือบีบอัดใหม่โดยอัตโนมัติ ภาพต้องเป็นแนวนอนอัตราส่วน 1.2–1.8 และผ่านการตรวจไฟล์จริง รองรับ raw Base64 แบบ canonical ไม่มีการดึง URL ภายนอกหรือ SVG

พื้นหลังเริ่มต้น `/assets/certificates/nkg-2569-white-gold.png` เป็นแบบที่ยืนยันเมื่อ 9 พ.ย. 2569 ขนาดเดิม 1497 × 1055 พิกเซล เก็บไฟล์นี้คงเดิมเพื่อรักษาฉบับที่อ้างถึงแม่แบบเริ่มต้น ใช้หน้าตั้งค่าหรือไฟล์ชื่อใหม่สำหรับแบบรุ่นถัดไป ลายเซ็นจริงยังต้องจัดเตรียมในพื้นหลังโดยผู้จัด

## กติกาผู้รับ

- นักกีฬาตัวจริง/สำรองได้รับเหรียญเดียวกับทีม ผู้ฝึกสอนระบุเหรียญดีที่สุดของทีมในรายการนั้น ผู้ที่มีส่วนร่วมแต่ไม่ได้เหรียญได้รับประเภทเข้าร่วม
- ไม่ออกจากการแข่งขันที่ยังไม่จบหรือชิงอันดับ 3 ยังไม่เสร็จ
- กรีฑาจัดเหรียญตามคนและรายการที่ลงทะเบียน รวมผู้ตกรอบที่มีผลคัดเลือกยืนยันแล้วเป็นผู้เข้าร่วม ไม่นำเหรียญของเพื่อนร่วมโรงเรียนไปให้ทุกคน
- DNS อย่างเดียวไม่ถือว่าเข้าร่วม หมายเลข/ผู้แข่งขันที่ระบุไม่ได้ หรือทีมผลัดที่ไม่ได้ลงทะเบียน จะต้องแก้ข้อมูลก่อนเผยแพร่

## การเก็บและสิทธิ์

ใช้ versioned JSON ใน private bucket `team-files`: `certificate-settings/` และ `certificate-issues/<competition-id>/` ผ่าน server-auth และ Storage CAS เดิม ไม่มี migration, schema, constraint, RLS หรือคีย์ใหม่ PDF/ZIP สร้างตามคำขอพร้อมฝัง Sarabun และภาพ ไม่บันทึกไฟล์รายบุคคลไว้ใน public directory

QR เปิดหน้า `/certificates/verify` ด้วย UUID สุ่ม แสดงเฉพาะเลขเกียรติบัตร ชื่อผู้รับ โรงเรียน รายการ รางวัล และวันที่ออก ไม่แสดงเบอร์ติดต่อหรือไฟล์ลายเซ็นแยก การ reset การแข่งขันเดิมไม่ลบประวัติเกียรติบัตร

## การตรวจสอบ

193 Node tests ผ่าน รวม 26 กรณีใหม่ด้านสิทธิ์โรงเรียน การเผยแพร่/ยกเลิก เวอร์ชันและ fingerprint ข้อมูล ภาพ Base64 ไฟล์ PDF/ZIP ฟอนต์ไทย eligibility และรายการกรีฑา ผ่าน TypeScript และ production build ไม่รัน E2E ตามคำสั่งเดิมของผู้จัด
