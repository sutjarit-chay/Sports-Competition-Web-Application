# นครโกสัมพีเกมส์ · ปีการศึกษา 2569

Next.js App Router + TypeScript + Tailwind CSS + Supabase. รองรับ 10 โรงเรียน และฟุตบอล วอลเลย์บอล แชร์บอล เปตอง เซปักตะกร้อ กรีฑา โยนบอล ปิงปอง

## เริ่มใช้งาน

Node.js 24, npm 11

```sh
npm ci
npm run dev
```

เปิดเว็บที่พอร์ต 3000 โหมดสาธิตเริ่มต้นโดยไม่ต้องใช้คีย์ ข้อมูลเก็บใน localStorage ของเบราว์เซอร์นั้น ใช้เมนูโรงเรียน / บัญชีเพื่อแก้ชื่อโรงเรียนทั้ง 10 แห่ง (ชื่อเริ่มต้นเป็นชื่อชั่วคราว) ทดลองสิทธิ์ หรือล้างข้อมูลสาธิต ข้อมูลไม่ได้ sync ข้ามอุปกรณ์

## Supabase จริง

1. สร้าง Supabase project และรัน `supabase/schema.sql` ใน SQL editor เพียงครั้งเดียว
2. คัดลอก `.env.example` เป็น `.env.local` ใส่ Project URL และ **anon/publishable key** เท่านั้น ห้ามใส่ service-role key ใน client หรือ Git
3. สร้างผู้ใช้ใน Supabase Auth แล้วกำหนดสิทธิ์ผ่าน SQL editor โดยใช้ UUID ของผู้ใช้จริง:

```sql
insert into public.profiles(id, role, school_id)
values ('USER-UUID-HERE', 'admin', null);
-- ผู้บันทึกผล: recorder / null
-- ผู้ประสานงาน: school / '1' ถึง '10'
```

4. Restart Next.js เปิดเมนูโรงเรียน / บัญชี เลือกโหมด Supabase แล้วเข้าสู่ระบบด้วย email/password

RLS: ผู้ชมอ่านโรงเรียน ตารางแข่ง ผลกรีฑา และเหรียญได้ ผู้ประสานงานอ่าน/เขียนนักกีฬาเฉพาะโรงเรียนตัวเอง ผู้บันทึกผลอ่านนักกีฬาและจัดการตาราง/ผล/เหรียญ ผู้ดูแลจัดการได้ทั้งหมด ไม่มี client policy ให้แก้ profiles หรือยกระดับสิทธิ์ ผู้ใช้ที่ไม่มี profile เป็นผู้ชม

## การแข่งขัน

- เลือกกีฬา รุ่น (ข้อความที่ต้องใช้ตรงกัน) และเพศก่อนจัดการ
- นักกีฬา: เพิ่มรายคนหรือนำเข้า CSV UTF-8 ตามแบบใน `public/athletes-template.csv` ตรวจหัวตาราง ข้อมูลซ้ำ โรงเรียน 1–10 และชนิดกีฬา ขนาดสูงสุด 2 MB
- จัดสาย: เลือกโรงเรียนและชื่อสาย สร้างตารางพบกันหมดภายในสาย ป้องกันสร้างสายเดิมซ้ำ ระบุวันเวลาและสนามรายคู่ วันเวลาเป็นเวลาท้องถิ่นของสถานที่แข่งขัน (ประเทศไทย)
- บันทึกผล: คะแนนจำนวนเต็มไม่ติดลบ ตารางคะแนนแยกกีฬา/รุ่น/เพศ/สาย ใช้ชนะ 3 เสมอ 1 แพ้ 0 เรียงคะแนน ผลต่าง คะแนนได้ และรหัสโรงเรียน
- กรีฑา: รายการวิ่งที่เวลาเป็นวินาที จัดฮีต ระบุ OK/DNS/DNF/DQ และคัดนักกีฬาเข้ารอบชิงเอง รองรับอันดับร่วม รายการกระโดด/ขว้างที่ค่าสูงชนะยังไม่มีหน้าจอรองรับ
- เหรียญ: ผู้มีสิทธิ์ยืนยันเหรียญจากรอบชิงเอง แยกรายการ/รุ่น/เพศ เรียงทอง เงิน ทองแดง ไม่ให้ผลฮีตสร้างเหรียญอัตโนมัติ
- PDF: เปิดหน้าที่ต้องการแล้วกดพิมพ์ / บันทึก PDF เลือก Save as PDF ใน browser ใช้ A4 แนวนอนและฟอนต์ไทยที่ติดตั้งในเครื่อง ไม่ใช่บริการสร้าง PDF บน server

กติกานับคะแนนนี้เป็นค่าเริ่มต้นลีก ไม่ใช่คะแนนเซต/ไทเบรกเฉพาะกีฬาหรือโปรแกรมน็อกเอาต์ กรรมการต้องกำหนดรุ่น รายการ และการตัดสินอันดับร่วมตามระเบียบการแข่งขันก่อนใช้จริง

## ตรวจสอบ

```sh
npm test
npm run typecheck
npm run build
npm run test:e2e
```

E2E ใช้ Chromium ที่ `/usr/bin/chromium` (แก้ executablePath ใน playwright.config.ts สำหรับเครื่องอื่น) ทดสอบลงทะเบียน คงข้อมูลหลัง reload นำเข้า CSV จัดสาย บันทึกผล ตารางคะแนน เหรียญ สิทธิ์สาธิต และสร้าง PDF

RLS ต้องทดสอบกับ Supabase จริงด้วยบัญชีแต่ละสิทธิ์ก่อนใช้ข้อมูลนักเรียนจริง ดู `supabase/verify-rls.sql` ไม่มีการยืนยันว่า migration ถูกติดตั้งบน project ของคุณจนกว่าจะรันจริง

## GitHub และเผยแพร่

เก็บเฉพาะ `.env.example` ที่ไม่มีค่า `.env.local` ถูก ignore ห้าม commit credentials สร้าง GitHub main ให้เรียบร้อยก่อนตั้งค่า hosting หลัง push จึงเชื่อม deployment กับ repository และกำหนด environment variables ในระบบ hosting (ไม่ใช่ใน Git)
